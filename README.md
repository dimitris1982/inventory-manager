# Διαχείριση Αποθέματος Καφέ

Εκπαιδευτικό πρόγραμμα Python για τη διαχείριση αποθέματος
ενός προϊόντος: σακούλες καφέ.

Το αρχικό απόθεμα είναι 20 τεμάχια.

## Δυνατότητες

- Καταχώριση παραλαβών και πωλήσεων.
- Απόρριψη μηδενικών και αρνητικών ποσοτήτων.
- Απόρριψη πώλησης που ξεπερνά το διαθέσιμο απόθεμα.
- Εμφάνιση τρέχοντος αποθέματος και συνολικών τεμαχίων
  παραλαβών και πωλήσεων.
- Μήνυμα εξάντλησης όταν το απόθεμα είναι 0.
- Προειδοποίηση χαμηλού αποθέματος για 1–5 τεμάχια,
  κατά την εμφάνιση της αναφοράς.
- Επαναλαμβανόμενο μενού με επιλογή εξόδου.

## Εκτέλεση

Απαιτείται Python 3. Από τον φάκελο του project:

```bash
python main.py
```

## Παράδειγμα χρήσης

Με αρχικό απόθεμα 20 τεμαχίων:

1. Παραλαβή 10 τεμαχίων → απόθεμα 30.
2. Πώληση 7 τεμαχίων → απόθεμα 23.
3. Απόπειρα πώλησης 30 τεμαχίων → απόρριψη.

Η αναφορά εμφανίζει:

- Απόθεμα: 23 τεμάχια.
- Συνολικές παραλαβές: 10 τεμάχια.
- Συνολικές πωλήσεις: 7 τεμάχια.

Τα αρχικά 20 τεμάχια δεν προσμετρώνται στις νέες παραλαβές.

## Τι εξασκήθηκα να χρησιμοποιώ

Μεταβλητές, input, print, while, if/elif/else,
εμφωλευμένες συνθήκες και αθροιστές.

## Περιορισμοί πρώτης έκδοσης

- Υποστηρίζεται μόνο ένα προϊόν.
- Οι είσοδοι πρέπει να είναι ακέραιοι αριθμοί.
- Γράμματα ή δεκαδικές είσοδοι προκαλούν σφάλμα.
- Τα δεδομένα δεν αποθηκεύονται μετά τον τερματισμό.
- Κάθε νέα εκτέλεση ξεκινά με απόθεμα 20 τεμαχίων.

## Επόμενες βελτιώσεις

- Χειρισμός μη έγκυρης εισόδου με try/except.
- Αποθήκευση δεδομένων σε αρχείο.
- Υποστήριξη πολλών προϊόντων.
